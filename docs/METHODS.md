# Materials and methods

## Data

**HCP Young Adult S1200** (https://www.humanconnectome.org/study/hcp-young-adult):
FIX-cleaned resting-state fMRI (4 runs) and 7 task batteries, Glasser
MMP1.0 parcellation (360 parcels). Download/parcellation tooling is shared
with the sister repo `quantum-chaos-spectral-transitions` (Issue #1 there);
this repo adds the density-matrix layer on top.

## State construction

1. Clean each parcel series (demean, z-score, band-pass 0.01–0.10 Hz; task
   runs additionally block-regressed for mean evoked responses).
2. FC: Pearson correlation matrix C (360 × 360), computed per subject per
   condition, and in sliding windows (60 s, 50% overlap) for trajectory
   analyses.
3. Density matrix: `rho = covariance_to_rho(C)` — validates symmetry/PSD and
   normalises to unit trace. For correlation matrices tr C = 360, so
   rho = C / 360.
4. Guard rail: FC matrices that fail the PSD check beyond numerical slack
   (can happen with aggressive denoising) are projected to the nearest PSD
   matrix (eigenvalue clipping) and flagged.

## State summaries

- `von_neumann_entropy(rho, base=2)` and normalised S/ln d.
- `purity`, `effective_rank`, Renyi spectrum S_q for q in {0.5, 1, 2, 4, 8}.
- All summaries get bootstrap CIs over time points (circular block bootstrap,
  block 30 s, 1 000 resamples) to respect autocorrelation.

## State-space geometry

- Pairwise root fidelities `fidelity_matrix` across all (subject × condition)
  states in an analysis set.
- `bures_distance` for MDS embedding (metric SMACOF, scikit-learn) and
  geodesic/radius analyses; `trace_distance` for distinguishability.
- Condition clustering assessed by silhouette score on Bures distances vs
  10 000 label permutations.

## Null models

1. **Wishart null**: white-noise covariance with matched T/d per condition —
   the entropy/purity/effective-rank floor (even noise has S < ln d when
   T < ∞; our baselines must come from the null, not the theory max).
2. **Phase randomisation** per parcel: kills cross-parcel sync, keeps
   spectra.
3. **Label permutation** for clustering and fingerprint statistics.

## Hypothesis tests

- **H1**: LMM S_norm ~ condition + (1|subject) + motion + T; task vs rest
  contrast, Bonferroni across 7 tasks. Same model for effective rank.
- **H2**: silhouette (Bures) vs permutation null; reported with and without
  global-signal regression.
- **H3**: day-2 → day-1 top-1 identification via root fidelity; chance =
  1/N; binomial test plus Finn-style rank statistic.
- **Falsifier check**: regress d_B(condition pair) on the pair's
  trace-norm/mean-correlation differences; if residual condition effect ~ 0,
  declare redundancy.
